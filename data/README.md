# Data dictionary: `data/raw/events.csv`

One row = one past campus event. The sample file is **synthetic** (generated by
`python -m ml.data.make_raw`). Replace it with real event records when you have them.

| Column | Type | Meaning | Known problems in the raw file |
|---|---|---|---|
| event_id | text | Unique id | dropped before modelling |
| event_name | text | Title | dropped before modelling |
| category | text | Academic, Career, Sports, Cultural, Social, Workshop | mixed case, extra spaces |
| venue | text | Classroom, Library Hall, Main Hall, Auditorium, Outdoor Field | mixed case |
| event_date | date | `YYYY-MM-DD` | some missing |
| start_time | text | `14:00` or `2:00 PM` | two formats |
| is_free | text | Yes/No | also `Y`/`N` |
| ticket_price | number (USD) | 0 for free events | blank for free events |
| capacity | integer | Seats available | impossible values (-1) |
| promo_days | integer | Days the event was advertised before it happened | |
| speaker_rating | number 1-5 | Rating of the main speaker/performer | missing, impossible values (9) |
| exam_week | 0/1 | Event held during exam week | |
| **attendance** | integer | **Target:** people who attended | missing, larger than capacity |

If your real data has different columns, edit `ml/config.py` (`FEATURE_SCHEMA`),
`ml/features.py` and the rules in `ml/data/make_dataset.py`.
